## Client List — `/clients`

```text
+--------------------------------------------------------------+
| Happy Bank                                         Clients   |
+--------------------------------------------------------------+
|                                                              |
|  Clients                                                     |
|  +--------+------------------+--------------------+--------+ |
|  | Number | Name             | National ID number |        | |
|  +--------+------------------+--------------------+--------+ |
|  | 1      | Alice            | 900101/1234        | Detail | |
|  | 2      | Bob              | 850515/5678        | Detail | |
|  | 3      | Charlie          | 920303/9012        | Detail | |
|  +--------+------------------+--------------------+--------+ |
|                                                              |
+--------------------------------------------------------------+
```

The whole row is clickable, "Detail" is a link for keyboard users.
